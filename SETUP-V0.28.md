# SOULBOUND v0.28 — Recorded Fantasy Audio + Large Battle Arena + EXP

**Branch:** `v0.28-recorded-audio-exp-arena` based on `v0.26.1b-audio-specialization-hotfix`.

## Code installed on the branch
- Replaces the synthesized `audio.js` script with `public/audio-real.js`. Uses actual OGG/MP3 CC0 recordings over HTTPS. The sounds are not generated by oscillators or chiptunes.
- Real sliced-metal sound for sword, heavy chop and metal impact for blunt, alternative staff/impact sound, guard/attack hits and item/UI clips using CC0 Kenney samples.
- Fantasy soundtrack selection changes across 6 biomes. Source URLs and license details in `CREDITS-V0.28.md`.
- Music and SFX sliders remain separately controllable from ⚙ AUDIO. The audio panel displays loading/fallback status.
- Larger combat viewport at desktop zoom 100%, intentionally cropping a bit of the high-res background rather than distorting it.
- Adds visible gold EXP bar below character status, with exact `XP / next-level target` text and progress calculated from the server state.
- Preserves class specialization popup, equipment/inventory, multiplayer, server battle rules, and save schema. No changes to `server.js` or SQL.

## Limitations — important
- **The actual recorded audio files have NOT been uploaded into this repository.** They are streamed from OpenGameArt and public GitHub hosts. If the source blocks cross-site playback, is temporarily offline, or changes its URLs, that audio will fail. Music has a CC0 fallback track. The Audio status box reports failures.
- Not browser-tested on Render, no claim that every external music URL is actually accessible from clients.
- This v0.28 is a working code integration proposal, not a fully self-hosted asset release. A production-ready follow-up should vendor the licensed audio files and change the URL mappings.
- Real weapon samples from the Kenney RPG and Impact audio collections are stylized recordings, not ultra-realistic high-budget sound effects.
- Because the scene is now taller, narrow/short monitors might scroll to the Character Attributes panel at 100% zoom. The screenshot request prioritized a larger battle scene.

## Test on Render
1. Set Render branch to `v0.28-recorded-audio-exp-arena`, save, deploy, then Ctrl+F5.
2. Enable MUSIC and listen; watch Audio status and confirm actual recording plays. Try each biome 1, 5, 9, 13, 17 and 21.
3. Use sword, mage and tank skills with SFX enabled; listen for the sampled sounds rather than synthesized bleeps.
4. Gain EXP and compare displayed value, progress bar, and level-up reset.
5. At level 5, test specialization popup. Open equipment/inventory, shop, use potions, restart, multiplayer party and saved-hero Continue.
6. Check zoom 100% and 90% and screenshot if elements overlap.
