# SOULBOUND character selection artwork

The v0.64/v0.65 character selection UI expects these **15 images** in this directory:

- `guild-hall.webp` (a 1672 × 941 seven-hero scene)
- `{corin,seris,lyra,kaiya,aren,vera,noct}-portrait.webp` (seven thumbnail portraits)
- `{corin,seris,lyra,kaiya,aren,vera,noct}-full.webp` (seven large portraits)

Image art comes from the project owner's supplied character sheets, with the shared guild scene created for the selection screen. These image files must be uploaded separately to this folder; this README does not include the binary assets.

Character mapping: Corin = Elias; Seris = Blue-Haired Woman; Lyra = Starter Heroine; Kaiya = Kaiya; Aren = Ryo; Vera = Silver-Haired Woman; Noct = Raine.

Paths are already configured in `public/characters-v064.js` and `public/character-select-v064.js`. Do not rename the `.webp` files.
