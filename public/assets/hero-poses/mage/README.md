# Mage PNG asset slot (SOULBOUND v0.55.6)

Upload the **six separate PNG files** from `SOULBOUND_Mage_6_Individual_PNG.zip` into this directory, not the original 2×3 pose sheets.

- `male_idle.png`
- `male_hit.png`
- `male_attack.png`
- `female_idle.png`
- `female_hit.png`
- `female_attack.png`

Each file contains **one** standalone pose. The static poses switch on idle, HP loss, and local attack actions; they are not frame-by-frame animations.

If assets are missing, the game falls back to its prior Mage SVG art. This code intentionally does not change combat balance, progression, saves, or equipment state.
